# Dr. Abiodun Joseph Fatoba — Academic Website

A responsive, static academic website for Dr. Abiodun Joseph Fatoba, focused on Computational Genomics and Statistical Genetics.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current-year footer
- `assets/abiodun-fatoba.jpg` — professional portrait
- `assets/Dr-Abiodun-Fatoba-CV.pdf` — downloadable academic CV

The publications section features six selected papers, led by the 2026 *Human Genetics* article. The DOI and ResearchGate links for that article are included as supplied; please test the DOI destination before public launch.

## Preview locally
Open `index.html` in a modern web browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named `yourusername.github.io` (or another repository for project pages).
3. Upload the contents of this folder to the repository root.
4. In repository Settings → Pages, select deployment from the `main` branch and `/ (root)`.
5. GitHub will provide a public URL after deployment.

## Custom domain
The preferred domain is `drabiodunfatoba.com`. Register it with a domain registrar after checking availability. In GitHub Pages settings, add the custom domain and configure the DNS records specified by GitHub for the account. Enable HTTPS after DNS verification. Domain availability and registration have not been checked or purchased as part of this package.
